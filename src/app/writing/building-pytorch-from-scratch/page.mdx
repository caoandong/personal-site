## Tensor

at its core there is this tensor object
basically a multi-dimensional array plus gradients

at its core it needs to behave like this

```python

x = Tensor([[1, 2, 3],
            [4, 5, 6]], requires_grad=True)   # shape (2, 3)

w = Tensor([10, 20, 30], requires_grad=True)   # shape (3,)

y = x * w                                     # broadcast w -> shape (2, 3)
loss = y.sum()                                # scalar
loss.backward()

```

so from this example the `Tensor` class needs to look something like this:

```python

class Tensor:

    def __init__(
        self,
        data,
        requires_grad: bool,
    ):
        ...

    def __mul__(self, other) -> Self:
        raise NotImplementedError
    
    def sum(self) -> Self:
        raise NotImplementedError

    # and a bunch of other operations like addition and subtraction etc

    def backward(self) -> None:
        raise NotImplementedError

```

## Indexing

under the hood tensor is just a list of numbers with a mechanism (or a "view") to index and divide the list so that it can represent multi-dimensional arrays


for example

generally speaking, to get the value at [x1, x2, ..., xn] the actual position in the storage is

```python
  x1 * shape[1] * shape[2] * ... * shape[n-1] \
+ x2 * shape[2] * shape[3] * ... * shape[n-1] \
+ xn
```

these coefficients for each dimension are precomputed into a list called `strides`

```python
  x1 * stride[1] \
+ x2 * stride[2] \
+ xn
```

therefore translating the index to storage position is simply

```python
def index_to_position(index, strides):
    sum(i * stride for i, stride in zip(index, strides))
```

## Matrix Multiplication

In general a multi-dimensional matrix multiplication is just a bunch of 2D matrix multiplications.
More precisely, in matmul `C = A @ B` we contracts A's last axis with B's second-to-last axis.

for 2D: 

C_{ik} = \sum_{j} A_{ij} B_{jk}

for 3D:

C_{hik} = \sum_{j} A_{hij} B_{hjk}

for high dimensions it's literally the same thing except that there are more dimensions in front

C_{...ik} = \sum_{j} A_{...ij} B_{...jk}


so in code we literally have

```
for every output index (...batch, row, col):
    total = 0
    for inner in range(n):
        total += A[..., row, inner] * B[..., inner, col]
    C[..., row, col] = total
```
