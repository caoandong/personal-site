# Revisiting Transformer

the fact that it can just generalize from the existing token and infer implicit rules based on the context is absolutely bonkers
so this makes me wonder: what is the minimum set of principles that we absolutely need to make this possible? without knowing the architecture apriori, let's say we are time-travelling to early 2010s, is it possible to derive the capabilities and the architecture from the first principles?

so what is in-context learning exactly? I think the most typical example is function induction
