# Building a GPU from First Principles

What is a GPU?

At the most basic level, the GPU is a machine that executes instructions on data in parallel.
<GpuHighLevelVisualization />

For example, in the figure above, the GPU executes the following vector add operation on array `A` and `B` and saves the outputs to `C`.

```cpp
__global__ void vector_add(const int* A, const int* B, int* C) {
    int i = threadIdx.x;
    C[i] = A[i] + B[i];
}

int main() {
    // ... Allocate and initialize A, B, and C.

    vector_add<<<1, 2>>>(A, B, C); // Launch one block with two threads.
    cudaDeviceSynchronize();

    // ... Read C and free the arrays.
}
```

The syntax `vector_add<<<1, 2>>>` divides the work into `1` block, and each block contains `2` threads. In general we can use `<<<blockDim, threadDim>>>` syntax to launch `blockDim` blocks and `threadDim` threads.

Each thread handles one piece of the work. Each thread has access to its `blockId` and `threadId` that tells it which piece to process.

The code above is compiled to assembly (SASS) code and submitted to the GPU:


```nvidia-sass
.text.vector_add:
    S2R         R6, SR_TID.X ;                    // tid = threadIdx.x
    MOV         R7, 0x4 ;                         // sizeof(int)
    ULDC.64     UR4, c[0x0][0x118] ;              // global-memory descriptor

    IMAD.WIDE   R2, R6, R7, c[0x0][0x160] ;      // A + tid*4
    IMAD.WIDE   R4, R6.reuse, R7.reuse, c[0x0][0x168] ; // B + tid*4

    LDG.E       R2, desc[UR4][R2.64] ;            // A[tid]
    LDG.E       R5, desc[UR4][R4.64] ;            // B[tid]

    IMAD.WIDE   R6, R6, R7, c[0x0][0x170] ;      // C + tid*4
    IADD3       R9, R2, R5, RZ ;                  // A[tid] + B[tid]
    STG.E       desc[UR4][R6.64], R9 ;            // C[tid] = result

    EXIT ;
```
